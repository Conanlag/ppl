# ppl

## Requisitos
- Instalar git
- Tener instalado linux o WSL


## 1. Como clonar el repositorio
ejecutar el siguiente comando
´´´
git clone https://github.com/Conanlag/ppl
´´´
crear tu propia rama
´´´
git branch <nombre>
´´´
cambiar de rama
´´´
git checkout <nombre>
´´´
hacer commit
´´´
git add .
git commit -m mensaje
´´´
subir los cambios a la rama 
´´´
git push origin <rama>
´´´
Pasar los cambios de la rama propia a la rama principal
´´´
git merge main
´´´
y para confirmar los cambios revisar manualmente si hay problemas en el merge, en el caso que no
´´´
git push origin main
´´´

Importante: antes de subir algun cambio asegurarse de que sean los cambios actuales en el main para asegurarse hacer git pull
´´´
git pull origin main
´´´
